# Service Request System
This repository is for the development and deployment of an internal servicing request system to be used by the VPA and corresponding units under them.  

## Basic Developer Environment Configuration
```powershell 
powershell

git clone <URL>
git checkout -b <branch>
git pull origin <branch>
git branch --set-upstream-to=origin/<branch> <branch>

uv lock
uv sync
.venv/Scripts/activate
```
